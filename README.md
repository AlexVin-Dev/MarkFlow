# MarkFlow

📝 Простой CMS-движок для публикации контента через Markdown-файлы

## Особенности

- ⚡ Мгновенное преобразование Markdown в HTML
- 🔐 Защита от Path Traversal
- 📌 Мета-данные через YAML Front Matter
- 📱 Адаптивный минималистичный дизайн
- 📂 Готовые шаблоны страниц
- 🛡 Встроенная страница 404

## Требования

- PHP 7.4+
- Любой веб-сервер (Apache/Nginx/Caddy)
- Доступ для записи в папку `markdown`

## Быстрый старт

1. Скачайте архив и залейте на хостинг:
```bash
git clone https://github.com/AlexVin-Dev/MarkFlow.git
```


2. Создайте свою первую страницу:
```bash
echo "---\ntitle: Привет мир\ndescription: Моя первая статья\n---\n# Добро пожаловать!" > markdown/my-page.md
```

## Структура проекта

```
markflow/
├── markdown/         # Все .md файлы
│   ├── main.md       # Домашняя страница
│   └── 404.md        # Страница ошибки
├── includes/
│   ├── Parsedown.php # Встроенный парсер
│   ├── header.php    # Шапка (редактируйте здесь)
│   └── footer.php    # Подвал (кастомизируйте)
└── index.php         # Ядро системы
```

## FAQ

❓ **Как создать новую страницу?**  
→ Добавьте файл `your-page.md` в папку `markdown` и перейдите по адресу `?page=your-page`

❓ **Как изменить шапку сайта?**  
→ Редактируйте файл `includes/header.php`
