# 🌐 **Fovo**  
Минималистичный проводник в мир организованных ссылок  

---


### ✨ **Концепция в трёх аккордах**
```markdown
1. 🎨 Чистый Markdown — без интерфейсного шума  
2. 🔒 Персональный архив — редактирование только для автора  
3. 🌍 Публичный доступ — делитесь коллекцией одной ссылкой
```


---

## 🛠 **Архитектура платформы**

### 📌 Ядро системы
| **Компонент**       | **Реализация**               | 
|---------------------|------------------------------|
| **Хранение данных** | Git-репозиторий с версиями   | 
| **Рендеринг**       | React + Markdown-it          |
| **Авторизация**     | JWT-токены через Telegram Bot|

---

## 🎯 Use Cases

### 👩💻 Создатель контента
```markdown
![Workflow](https://example.com/fovo-flow.png)
1. Набирает текст в любимом редакторе (VS Code/Typora)
2. Пушит изменения через Git CLI
3. Обновлённая коллекция мгновенно отображается на сайте
```

### 👀 Зритель
```markdown
[Пример живой страницы](https://velfan.ru/favo/?page=test)  
- Просмотр в трёх режимах: RAW/Preview/Презентация
- Копирование ссылок в 1 клик
- Темная/светлая тема
```




### 💡 Доступ к созданию коллекций  
Отправьте **Telegram-сообщение** администратору с тезисами:  
- Цель использования платформы  
- Предполагаемый объём контента  
- Желаемый домен (ваш_ник.fovo.link)  

Одобренные пользователи получат:  
✅ Персональный Git-репозиторий  
✅ Webhook для автоматического деплоя  
✅ Статистику просмотров через Plausible
